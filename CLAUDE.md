# Project instructions

## Git

- Never push to any git remote (`git push`), and never create pull requests, for this repository. Local commits only.
- Do not ask whether to push, do not suggest pushing, and do not set up a remote. If asked to "sync" or "back up" the repo, use a local mechanism (e.g. a commit), not a push.
- Only create commits when the user explicitly asks for one, in the current batch of work being confirmed.
